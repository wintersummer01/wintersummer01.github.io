---
title: Secure Semantic Communication via Steganography
slug: secure-semantic-communication-via-steganography
---

Private content is hidden inside a host image before wireless transmission. An authorized receiver reconstructs both images, while an eavesdropper sees only the host content.

The full Python prototype runs over USRP radios. A masking module separates the two streams before semantic decoding.
